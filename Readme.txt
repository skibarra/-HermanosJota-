Mueblería Hermanos Jota

Sitio web desarrollado para una mueblería familiar.

El proyecto permite visualizar productos, consultar sus detalles, utilizar un buscador, agregar productos a un carrito y enviar consultas mediante un formulario de contacto.

Tecnologías

* HTML5
* CSS3
* JavaScript
* LocalStorage

Funcionalidades

* Página de inicio.
* Catálogo de productos.
* Buscador.
* Detalle de productos.
* Carrito de compras.
* Formulario de contacto.
* Validación mediante JavaScript.
* Compra simulada.
* Diseño responsive.
